## 🚀 Deployment Options

### Option A: GitHub Pages

1. Push to a GitHub repository.
2. Go to **Settings** > **Pages**.
3. Choose the `main` branch and `/root` directory.
4. Your site will be live at:
   `https://<your-username>.github.io/<repo-name>/`

### Option B: Netlify

1. Visit [Netlify](https://www.netlify.com/).
2. Drag-and-drop the folder or connect your GitHub.
3. Get a free custom subdomain like:
   `https://patrick-portfolio.netlify.app`
